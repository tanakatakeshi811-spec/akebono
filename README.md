# あけぼの — 光と音で目覚めるアラーム（PWA）

iPhone・Android・PC のブラウザから「ホーム画面に追加（インストール）」して使うWebアプリです。
アプリ本体は `index.html` 1ファイル。ほかのファイルはインストールとオフライン動作のためのものです。

```
index.html            アプリ本体（HTML・CSS・JSすべて入り）
sw.js                 オフライン用（service worker）
manifest.webmanifest  アプリ名・アイコンの情報
icons/                アイコン
```

## 1. ネットに置く（HTTPSが必要）

カメラ・マイク・インストールはHTTPSのページでしか動きません。無料で置ける例：

**GitHub Pages**
1. GitHubで新しいリポジトリを作る（例：`akebono`、Public）
2. 「uploading an existing file」から、このフォルダの中身をすべてドラッグ（`icons` フォルダごと）→ Commit
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 1〜2分で `https://ユーザー名.github.io/akebono/` が開けるようになります

**Netlify Drop**：https://app.netlify.com/drop にフォルダごとドラッグ（URLを残すにはアカウント登録）

PCだけで試すなら、このフォルダで `python -m http.server 8000` を実行して `http://localhost:8000` を開いてもOKです。

## 2. インストール

- **iPhone / iPad（Safari）**：共有ボタン →「ホーム画面に追加」→「Webアプリとして開く」をオン → 追加。以後はホーム画面のアイコンから開く
- **Android（Chrome）**：メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」
- **PC（Chrome / Edge）**：アドレスバー右のインストールボタン。Mac の Safari は「ファイル」→「Dockに追加」

## 3. 使い方

1. 寝る前に「おやすみモードへ」→ 起きる日と時刻・気分・入眠サウンドを選んで「おやすみなさい」
2. スマホは充電しながら、画面を上にして顔から30〜50cmの枕元へ。画面の明るさは最大（自動調整オフ）
3. 朝：浅い眠りを検知（または設定時刻の20分前）から、実際の空と同じ軌道の日の出が始まり、設定時刻に毎朝かわる音楽と自然音が流れます
4. 「声（今日やりたいことを一言）」「光（窓辺や照明をカメラに3秒）」「深呼吸（4秒吸って6秒吐く×3）」のどれかで止まります
5. 止めると、天気・朝のことば・占い・ゆうべの眠りのグラフが出ます

### 今日だけ・その日だけの起床

ホームの「この日だけ」を押すと、日付と時刻を選んで**その1回だけ**のアラームをセットできます（「今日」「明日」「20分後」「30分後」「90分後」のボタンつき）。平日・土日のくり返し設定はそのまま残ります。今日の数十分後にもセットできるので、昼寝にも使えます。使い終わるか時刻が過ぎると自動で消えます。

### ホームでわかること

最初の画面に、**いまの時刻（秒まで）**・**今日の天気と気温（〇〇市・何度・最高/最低）**・**今日の占い**・**今日の一言**・**今日のニュースの見出し**が出ます。占いと一言は、朝に出るものと同じ内容です。

- 天気の場所は、設定の「天気の地域」から選べます。一覧にない街は**市町村名で検索**できます（全国どこでも）。
- 「現在地から自動で決める」をオンにすると、開くたびに現在地を読み取り、その場所（〇〇市）の天気になります。
- ニュースは上の「ニュース」から一覧が開きます。見出しを押すと**アプリの中で要約**が読めます（全文は配信されていないため、続きは「全文を読む」でNHKのページが開きます）。アラームを止めたあとの画面の「ニュースを見る」も、同じアプリ内の一覧に変わりました。

### ドット絵モード

設定の「見た目」→「ドット絵モード」をオンにすると、空も画面もドット絵（粗い四角と少ない色）になります。描く点が少ないので動作も軽くなります。

## 4. 大事な注意

- **アプリを開いたまま（画面をつけたまま）でないと鳴りません。** ほかのアプリに切り替えたり画面を手動で消したりしないでください。念のため標準の時計アプリにも予備アラームを入れておくと安心です
- iPhone：ホーム画面アプリで画面の消灯を防げるのは iOS 18.4 以降（それ以前は動画再生で代用）。消音モードでも鳴るのは iOS 17 以降
- iPhone のホーム画面アプリでは音声認識APIが使えないため、「声」は声の長さと抑揚で判定し、録音を端末に保存します
- iPhone では夜間のマイク使用で音の出力先が受話口に切り替わる不具合が報告されているため、マイク計測は初期設定オフです（設定でオン可）
- 天気は Open-Meteo（無料・キー不要）から取得します。データはすべて端末内（IndexedDB）に保存されます
- 医療機器ではありません。睡眠の深さは体動と音からの推定です

## 5. 動作確認用モード

URLの末尾に `?debug&speed=60` を付けると、時間が60倍で進み、右側に「+10分」「準備開始」「アラーム」ボタンが出ます。`&fast` を足すと止め方の判定時間が1/10になります。

## 6. 更新したとき

`sw.js` の先頭の `VERSION` を変えて置き直すと、次に開いたときに新しい版へ切り替わります。
